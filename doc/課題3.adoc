#  課題3

## 要求事項
ロボット開発におけるご自身のスキルを示すプログラムを制作してください。 
ロボットそのものを扱うプログラムでなくとも、ロボットソフトウェア開発に通じるようなアルゴリズムに関するものや、実デバイスとの接続を意識したプログラムであるとより好ましいです。
既存の成果物を活用しても、新規に作成いただいても構いません。 

## 条件 / Requirements
* プログラムの目的・仕様・アピールポイントを説明する資料の添付
* 既存の成果物を提出する際に、チームで開発したものである場合はご自身が関与した部分を明らかにしてください

## 【注意事項 / Important Notes】
◎ 使用言語はC++ または Pythonであること +
◎ オブジェクト指向を意識した実装であること  +
◎ コードの保守性・可読性およびコメントも評価対象とします +
◎ AIツールの利用は可能ですが、提出いただいたコードについては後日の面接でご自身の言葉で説明していただきます +
◎ README には必ず以下を記載してください： +
　・ビルド方法・動作確認方法 +
　・プログラムの構成や背景（発想や狙い） +
　・工夫した点・アピールポイント +
　・AIツールを使用した場合、その内容と範囲  

## 【提出方法・期限 / Submission Method & Deadline】

・提出期限：本日より2週間以内 +
・提出形式：URL（Google Drive, GitHubなど） +
・ファイルにアクセス制限をかけないこと
